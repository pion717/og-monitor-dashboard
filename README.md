# 日常数据监控看板（在线版）

本页是**内部工具的展示壳**，仓库**不含任何数据源**，页面不预置数据。

- 完整功能请用本地数据目录的 `start_server.command` 打开，自动读取本地 CSV。
- 在本页试用可点上方「导入 Excel 数据」选择本地 CSV，但**列名必须与看板 21 列表头白名单精确匹配**（如 `周次` / `发件大区` / `目的大区` / `客户简称` / `OG首次签入时间(年-月-日)` 等）；列名对不上的维度会被静默丢弃、图表为空。含 `收入金额(管报)` / `记账成本(未税)` / `收入匹配` 等列时才显示经营分析图表。
- 列数不限定，但列名是硬门禁。
